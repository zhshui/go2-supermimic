# 混合地形与域随机化训练

训练从楼梯策略迁移，保持 4096 个环境和 SuperMimic 框架。

| 项目 | 配置 |
|---|---|
| 地形 | 5 种上下楼梯变体＋平地、粗糙地面、方块、双向坡面 |
| 比例 | 楼梯约 50%，其他地形约 50%，5 级难度课程 |
| 指令 | vx 0.2–0.8 m/s，vy ±0.15 m/s，偏航角速度 ±0.6 rad/s |
| 指令周期 | 每 3–6 秒重新采样 |
| 质量/惯量 | 每个身体启动时按 0.8–1.2 倍缩放，二者一致缩放 |
| PD 增益 | 各关节 Kp/Kd 在启动时独立按 0.8–1.2 倍采样 |
| 控制延迟 | 每回合 0/1/2 个控制步，即 0/20/40 ms；替代原执行器小延迟 |
| 推搡 | 每 3–6 秒施加水平速度脉冲，每轴 Δv ∈ [−0.4, 0.4] m/s |

原有脚底摩擦、COM、编码器和观测噪声仍保留。新增条件已经接入实际采样与想象优化；已通过短仿真核验，尚不代表新增条件下的能力已训练完成。

Actor 观测仍为 735 维，原空闲目标槽的前三项变为 vx、vy、偏航角速度指令。世界模型物理上下文从 4 维扩为 41 维，加入 13 个质量倍率和 24 个实际 PD 增益值。Critic 还接收指令与待执行动作队列。

延迟动作由同一可微队列算法处理，replay 保存实际执行动作。推搡发生前后的 replay 跨步会被屏蔽，世界模型从推搡后的状态学习恢复动力学。
